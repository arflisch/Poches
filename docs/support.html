Assistance

Une question, un problème ou une idée ? Ouvre un ticket sur GitHub.

Changer de téléphone : Réglages › Sauvegarder mes données, enregistre le fichier dans iCloud Drive, puis sur le nouveau téléphone Réglages › Restaurer une sauvegarde avec le même mot de passe.

Poches Pro sur un nouvel appareil : Réglages › Poches Pro › Restaurer mes achats, avec le même compte Apple.

Mot de passe de sauvegarde oublié : il n'est enregistré nulle part, la sauvegarde ne peut pas être ouverte sans lui.

Politique de confidentialité

Support

A question, a problem or an idea? Open an issue on GitHub.

Moving to a new phone: Settings › Back up my data, save the file to iCloud Drive, then on the new phone Settings › Restore a backup with the same password.

Poches Pro on a new device: Settings › Poches Pro › Restore my purchases, with the same Apple Account.

Forgotten backup password: it is not stored anywhere, so the backup cannot be opened without it.

Privacy policy

Ondersteuning

Een vraag, een probleem of een idee? Open een issue op GitHub.

Naar een nieuwe telefoon: Instellingen › Back-up van mijn gegevens maken, bewaar het bestand in iCloud Drive en kies op de nieuwe telefoon Instellingen › Back-up terugzetten met hetzelfde wachtwoord.

Poches Pro op een nieuw toestel: Instellingen › Poches Pro › Mijn aankopen herstellen, met hetzelfde Apple-account.

Back-upwachtwoord vergeten: het wordt nergens opgeslagen, dus de back-up kan zonder dat wachtwoord niet geopend worden.
